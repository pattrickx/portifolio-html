Side Projects

Projects under the Shrimp Dev brand — built with AI, modern web tech, and a multi-agent development system.

🦐

These projects are developed with the help of my Multi-Agent MoE System — an orchestration system of 39 specialized AI agents (Mixture of Experts) built on top of the Hermes Agent framework.

Each project leverages dedicated agents for backend development, frontend engineering, DevOps & infrastructure, code review & QA, security analysis, documentation, and architecture design — organized across 7 specialized layers. The system uses OpenRouter with automatic key rotation across 12 API keys for high availability.

ResumeMatch

AI-powered resume vs job matching SaaS. Upload a resume and job description to get compatibility scoring, skill gap analysis, salary estimation (3-tier), and improvement suggestions. Features 7 AI agents via OpenRouter, PDF parsing, sanitization with two-tier patterns, and a dark-themed React frontend. Deployed on Oracle VPS via Cloudflare Tunnel.
